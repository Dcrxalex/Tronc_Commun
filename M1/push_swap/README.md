# Push_swap

*This project has been created as part of the 42 curriculum by <aldecroi>, <ikryvenk>*

## Description

The goal of this project is to better understand algorithmic complexity. The objective is to write a program to sort numbers using only two stacks to manipulate: **stack A** and **stack B**. 

The program takes a list of numbers as an argument (which can be positive and/or negative numbers, within the possible values for an `int`). We stock them in stack A, where the first argument becomes the top of the stack.

### Available Commands

To sort the numbers, we can only use the following commands:

* **`sa`** (swap a): Swap the first two elements at the top of stack a. Do nothing if there is only one or no elements.
* **`sb`** (swap b): Swap the first two elements at the top of stack b. Do nothing if there is only one or no elements.
* **`ss`**: `sa` and `sb` at the same time.
* **`pa`** (push a): Take the first element at the top of b and put it at the top of a. Do nothing if b is empty.
* **`pb`** (push b): Take the first element at the top of a and put it at the top of b. Do nothing if a is empty.
* **`ra`** (rotate a): Shift up all elements of stack a by one. The first element becomes the last one.
* **`rb`** (rotate b): Shift up all elements of stack b by one. The first element becomes the last one.
* **`rr`**: `ra` and `rb` at the same time.
* **`rra`** (reverse rotate a): Shift down all elements of stack a by one. The last element becomes the first one.
* **`rrb`** (reverse rotate b): Shift down all elements of stack b by one. The last element becomes the first one.
* **`rrr`**: `rra` and `rrb` at the same time.

## Algorithms Implemented

We wrote 4 different algorithms for this project:

1. **Simple algorithm ($O(n^2)$):** Used for small sets of numbers.
2. **Medium algorithm ($O(n\sqrt{n})$):** Used for medium-sized sets.
3. **Complex algorithm ($O(n \log n)$):** Optimized for large datasets.
4. **Custom adaptive algorithm (learner’s design):** This algorithm dynamically chooses which strategy to use by calculating the "disorder" of the stack first:
   * If disorder is **less than 0.2**, it uses the Simple algorithm.
   * If disorder is **between 0.2 and 0.5**, it uses the Medium algorithm.
   * If the disorder is **high**, it uses the Complex algorithm.

## Instructions

To compile the program, you can use the following commands in the terminal:

* `make`: Compiles the main `push_swap` program.
* `clean`: Cleans the repository by removing object files.
* `fclean`: Cleans the repository and deletes the compiled programs.
* `re`: Recreates the program by running `fclean` and `make` again.

To execute the program, type `./push_swap` and provide the numbers as arguments. For example:
```bash
./push_swap 2 1 3 6 5
```

## Algorithms

For our complex algorithm, we chose to implement the **Turk Algorithm** because we found it to be one of the fastest and most efficient methods. 
   * **How it works:** At first, it pushes 2 elements from stack *A* to stack *B*.
     * Then, it calculates the move cost for every element from *A* to find its correct place in *B*. It chooses the cheapest element and pushes it to *B*. 
     * This process is repeated until only 3 elements are left in stack *A*, which are then sorted easily.
     * After that, it calculates the cost for pushing elements back from *B* to *A* and pushes all elements back into their correct positions.
     * Finally, it rotates stack *A* until the smallest element is at the top.
